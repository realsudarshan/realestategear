# @realestategear/tokens

Brand-neutral CSS tokens, Tailwind v4 mappings, class-name utilities, and the
build-time Real Estate Gear theme compiler.

```css
@import "@realestategear/tokens/preset.css";
@import "@realestategear/tokens/palette.default.css";
```

Applications using `@realestategear/ui` must also register that package as a
Tailwind source because dependencies are ignored by default.
